# Generated dice markings

Generated using the built-in ImageGen tool (not the API/CLI). The source is `source-glyphs.png`. Individual `0.svg` through `9.svg`, `pip.svg`, and `star.svg` contain traced vector paths with interior holes preserved. `glyphs.json` holds the same paths for the SVG face atlas. Trace reproducibly with `node scripts/trace-dice-marks.mjs` from the web repository.

## Final prompt

Use case: stylized-concept. Asset type: master artwork sheet for SVG markings on illustrated fantasy Dungeons-and-Dragons-style dice. Pure black ink on pure white background. A precise 4-column by 3-row grid of 12 separate equally spaced glyphs, no visible grid lines. Row 1 exactly: 0, 1, 2, 3. Row 2 exactly: 4, 5, 6, 7. Row 3 exactly: 8, 9, a solid round dice pip, a small four-point diamond star. All glyphs centered in their individual equal square cells with generous whitespace, consistent cap height and weight. Numerals are bold expressive fantasy engraved serif numerals, sharp wedge serifs, subtle organic hand-cut character, extremely legible at tiny size. Closed solid silhouettes, modest small engraved white cuts inside broad strokes, clean contours for vector tracing. No outlines around the glyphs, no tile borders, no background texture, no shadows, no gradients, no extra symbols, no other text. This is flat orthographic 2D game asset art, not an image of a die.
